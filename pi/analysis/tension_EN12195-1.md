# 벨트 장력 판정 기준: EN 12195-1:2010 정리와 구현 계획

벨트 장력 셀(인장형)로 "이 벨트가 화물을 붙잡기에 충분한가"를 판정하려고, 화물 고박 계산 표준
EN 12195-1:2010 의 장력 관련 규정을 정리했다. 뒤쪽에는 북쪽 · 남쪽 벨트 2개 구성으로 어떻게
구현할지 계획을 적었다.

## 요약

- 마찰 고박(벨트를 화물 위로 넘겨 누르는 방식)은 **벨트 장력 × 마찰**로 화물을 잡는다.
  필요 장력은 `ΣFT ≥ m·g·(c − μ·cz)·fs / (2·μ·sinα)` 로 정해진다 (식 10).
- 설계 가속도(도로): 전방 0.8 g, 후방 0.5 g, 측방 0.5 g (불안정 화물 전도 검토 시 0.6 g), 수직 1.0 g.
- 안전계수 fs: **전방 1.25, 측방 · 후방 1.1**.
- 상한: 조임 장력은 **0.5 LC 이하**, 운행 중 걸리는 힘은 **LC 이하**.
  불안정 화물이면 기울면서 늘어나는 장력도 0.5 LC 를 넘으면 안 된다.
- 표준은 STF(라벨 값)로 장력을 **추정**하지만, 우리는 장력을 **직접 잰다**.
  표준이 정의한 "tension force indicator"(3.1.4)가 바로 우리 장력 셀이다.
- 구현: 북(TN) · 남(TS) 벨트마다 **맡은 하중 몫**을 바닥 셀에서 구해 벨트별 필요 장력과 비교한다.
  여기에 IMU 실측 가속도로 **실시간 여유**를 보고, 출발 시점 대비 **느슨해짐**, 북남 **불균형**을 본다.

## 1. 출처와 확인 수준

표준 원문은 유료라 아래 공개 자료로 확인했다. 각 항목은 어디서 확인했는지 적었다.

| 자료 | 확인한 것 |
|---|---|
| EN 12195-1:2010 최종판 공개 미리보기 (SIST EN 12195-1:2011) | 적용 범위, 용어 정의, 표 2~4(가속도), fS = 1.1/1.25 · fµ = 0.75 도입, 대칭 고박 가정 |
| prEN 12195-1:2008 초안 미리보기 | 5.1 불안정 화물 규칙(0.5 LC, cy 0.6) 원문 |
| IRU *International Guidelines on Safe Load Securing for Road Transport* (2014, EN 12195-1:2010 기반) | 부록 B 마찰계수 표, 식 10 · 16 계산 예제, 0.5 LC · 10 % LC 프리텐션, 벨트 각도 범위, 재조임 권고 |
| 투르쿠대 Cargo Calculator 공식집 (2013) | 2010판 식 10 · 14~17 · 30~37 형태, fs 적용 방향 |
| Jagelčák, *Komunikácie* 4/2007 | 2003판 k 계수(1.5)의 문제와 2010판에서 k 를 지우고 fs 로 바꾼 경위 |

> 식 10(미끄럼)과 식 16(전도)은 IRU 계산 예제 숫자(10.9 t, 1.4 t, 8.9 t, 8.1 t)를 그대로 재현해서 검산했다.
> 판정 기준으로 박기 전에, 원문을 구할 수 있으면 5.4절(마찰 고박)과 부록 B · D 를 한 번 더 확인할 것.

## 2. 적용 범위 — 우리 모형에 그대로 맞는 표준은 아니다

- **총중량 3.5 t 이하 차량에는 적용하지 않는다.** 원문 주석에는 가벼운 차량은 가속도가 더 클 수 있다고 적혀 있다.
  우리 운반 대차 모형은 범위 밖이다. 그래서 **계산 방법과 계수를 빌려 쓰고**, 실제 가속도는 IMU 로 따로 본다(7.4절).
- **모든 식은 대칭 고박(앞뒤 · 좌우 대칭)을 가정한다.** 비대칭이면 따로 고려해야 한다고만 적혀 있고, 방법은 다루지 않는다.
  북 · 남 벨트 장력이 크게 다르면 표준 밖이므로 우리 규칙(불균형 판정)으로 덮는다.
- 미끄럼 · 전도 위험이 없는 화물이라도 진동으로 크게 밀리지 않게 고정해야 한다 (4.1).

## 3. 용어

| 기호 | 뜻 | 비고 |
|---|---|---|
| **STF** | Standard Tension Force. 래칫 핸들에서 손을 뗀 뒤 남는 장력 | 라벨에 daN 으로 표기. 표준 손힘 SHF 50 daN 기준 (EN 12195-2) |
| **LC** | Lashing Capacity. 사용 중 견디도록 설계된 최대 허용 힘 | MSL · SWL 과 같은 개념 |
| **FT** | 조임 장치로 만든 벨트 장력 | 마찰 고박 계산에 씀. 표준은 FT = STF |
| **FR** | 화물이 움직이려 할 때 벨트가 받는 구속력 | 직접 고박 계산에 씀. FR = LC 까지 |
| **fS** | 마찰 고박에서 장력 분포 불확실성을 덮는 안전계수 | 1.25 / 1.1 |
| **fµ** | 동적 마찰 / 부록 B 마찰계수 비 | 0.75. 직접 고박에만 씀 |
| **α** | 벨트와 바닥면 사이 수직 각도 | |
| **b, d** | 무게중심 → 전도 모서리 수평거리 / 무게중심 높이 | 전도 판정용 |
| tension force indicator | 벨트에 걸린 힘을 보여 주는 장치 (3.1.4) | **우리 장력 셀** |

단위: 1 daN = 10 N. 라벨의 LC 1600 daN = 16 kN.

## 4. 설계 가속도 (표 2, 도로)

| 고정 방향 | cx 전방 | cx 후방 | cy 미끄럼 | cy 전도 | cz 수직 |
|---|---|---|---|---|---|
| 앞뒤 | **0.8** | **0.5** | — | — | 1.0 |
| 좌우 | — | — | **0.5** | **0.5 / 0.6** (5.1 참조) | 1.0 |

- 표 값은 해당 운송 방식의 최대값이다. 앞뒤 · 좌우가 함께 걸리는 경우도 이 값으로 덮는다고 본다.
- 짧은 충격 · 고주파 진동은 벨트 신장과 현가장치가 흡수한다고 보고 무시한다.
- 철도(표 3) · 해상(표 4) 값도 있지만 우리와 무관하므로 생략.

**안정 조건 (전도 위험 없음):** `b / d > c / cz`. 도로 측방은 c = 0.5 로 본다.
무게중심이 화물 한가운데면 `b = 폭/2`, `d = 높이/2` 이므로 측방은 **높이/폭 < 2**, 전방은 **높이/길이 < 1.25** 면 안정.

## 5. 장력 규정

### 5.1 마찰 고박: FT = STF

계산에 쓰는 장력은 라벨의 STF 다. 표준이 실제 장력을 모르니 STF 로 대신하는 것이다.
**우리는 장력을 직접 재므로 STF 대신 측정값 T 를 넣는다.**

### 5.2 안전계수 fs

| 방향 | fs |
|---|---|
| 전방 | **1.25** |
| 측방 · 후방 | **1.1** |

### 5.3 "2" 계수와 모서리 장력 손실 (2003판 k → 2010판 fs)

- 마찰 고박 식의 분모에 있는 **2** 는 벨트 양쪽 다리를 뜻한다. 양쪽 다 FT 라고 보고 계산한다.
- 실제로는 화물 모서리 마찰 때문에 **래칫 반대쪽 다리 장력이 더 낮다.**
- 2003판은 이를 **k = 1.5** 로 반영했다. 래칫이 한쪽에만 있으면 반대쪽은 절반이라고 본 것이다.
  VDI 2700 은 반대쪽에 장력 표시기가 있거나 래칫이 2개면 k = 2.0 을 허용했다.
- 측정해 보니 k 가 2 를 넘는 경우도 있었고, k < 2 를 쓰면 전도 식이 특정 각도에서 무한대 · 음수가 되는 문제가 있었다.
  그래서 **2010판은 k 를 모든 식에서 지우고 2 로 고정한 뒤, 그 불확실성을 fs 로 덮었다.**
- **래칫은 한쪽에 몰지 말고 번갈아 둔다.** 벨트가 여러 개면 래칫을 좌우 교대로 배치하라는 것이 일반 요구사항이다.
  한쪽에만 두면 벨트가 오히려 화물을 그쪽으로 기울게 만들 수 있다.

### 5.4 상한: 0.5 LC

- 래칫은 손힘 50 daN 으로 **최소 10 % LC** 이상 조일 수 있어야 한다.
  반대로 손힘 50 daN 으로 낼 수 있는 조임 장력은 **최대 50 % LC** 다 (IRU 가이드의 래칫 요건).
- **불안정 화물 + 마찰 고박**이면, 화물이 기울면서 늘어나는 벨트 힘이 **LC 의 절반을 넘으면 안 된다** (5.1).
  벨트 수는 아래 두 계산 중 큰 쪽으로 정한다.
  - cy = 0.5, FT = STF
  - cy = 0.6, FT = 0.5 LC
  - 마찰 고박 대신 직접 고박을 쓰면 cy = 0.6, FR = LC 로 계산한다.
- 어떤 경우든 벨트에 걸리는 힘은 LC 를 넘으면 안 된다. 벨트가 걸리는 고리(lashing point) 강도보다 큰 LC 를 쓰면 안 된다.

### 5.5 하한: 위험이 없어도 최소한은 조인다

- 4.1: 미끄럼 · 전도 위험이 없어도 진동으로 밀리지 않게 고정해야 한다.
- IRU 가이드 권고: **화물 4 t 당 STF 400 daN 벨트 1개.** 화물 1 kg 당 약 1 N 이다.

### 5.6 직접 고박 (참고)

- 루프 · 스프링 · 직선 · 교차 고박은 벨트가 화물을 직접 잡는다. 벨트 힘은 **FR = LC** 까지 쓴다.
- 마찰은 **µ × fµ (fµ = 0.75)** 로 줄여 쓴다. 화물이 조금 움직인 뒤에 버티는 방식이라 동적 마찰을 쓰는 것이다.
- 우리 구성은 마찰 고박이므로 판정에는 쓰지 않는다.

### 5.7 벨트 각도 α

| α | IRU 표 사용법 |
|---|---|
| 75°~90° | 표 그대로 |
| 30°~75° | 벨트 2배 필요 (표 값 절반) |
| 30° 미만 | 마찰 고박 쓰지 말 것 |

식은 sinα 로 각도를 직접 반영하므로, 우리는 식을 그대로 쓰고 30° 미만이면 경고만 낸다.

> **양쪽 각도가 다를 때 (메모, 코드 반영 안 함)**: 식의 `2·sinα` 는 양쪽 다리 각도가 같다고 본 값이다.
> 화물이 치우쳐 한쪽이 α₁, 반대쪽이 α₂ 면 누르는 힘은 `T·(sinα₁ + sinα₂) = 2T·sin(평균 α)·cos(Δα/2)` 라서
> 각도 차 20° 여도 1.5% 만 준다. 바닥 셀 쪽에서는 `analysis/belt_fit.py` 가 이 힘을 `k·T` 로 직접 재고 있다
> (10-25 실측 k 1.8 ~ 2.1). 장력 하한도 `2·sin(TENSION_ANGLE)` 대신 추정한 k 를 쓸 수 있지만 차이가 5% 안이라 아직 그대로 둔다.
> 수평 성분 `T·(cosα₁ − cosα₂)` 가 무게중심을 옮겨 보이게 하는 영향은 `belt_fit.py` 문서에 적어 두었다.

### 5.8 운행 중 재조임

벨트 장력은 주행하면서 풀린다. IRU 가이드는 출발 후 조금 달린 뒤 장력을 확인하고, 운행 중에도
주기적으로 확인해 필요하면 다시 조이라고 권고한다. **우리 시스템이 이 확인을 자동으로 한다.**

## 6. 공식

### 6.1 미끄럼 — 마찰 고박 (식 10)

```
n ≥ m·g·(c − µ·cz) / (2·µ·sinα·FT) · fs
```

벨트마다 장력이 다르면 `n·FT` 를 `ΣT` 로 바꿔 필요 장력 합으로 쓴다.

```
ΣT_need = m·g·(c − µ·cz) · fs / (2·µ·sinα)
```

- c − µ·cz ≤ 0 이면 그 방향으로 미끄럼 위험이 없다.
- 검산 (IRU 예제): n = 2, µ = 0.45, α = 55°, FT = 4 kN 에서 벨트가 잡을 수 있는 질량을 식으로 풀면
  측방 · 후방 10.9 t, 전방 1.4 t 로 예제 값과 같다.

### 6.2 전도 — 마찰 고박, 한 줄 화물 (식 16)

```
n ≥ m·g·(cy·d − cz·b) · fs / (w·FT·sinα)
```

- w 는 화물 폭, d 는 무게중심 높이, b 는 무게중심에서 전도 모서리까지 수평거리.
- 불안정 화물이면 (cy = 0.5, FT = STF) 와 (cy = 0.6, FT = 0.5 LC) 두 번 계산해서 큰 n 을 쓴다.
- 검산 (IRU 예제): n = 2, h = 2.4 m, w = 1.0 m, α = 74° 에서
  STF 5 kN · cy 0.5 → 8.9 t, 0.5 LC 10 kN · cy 0.6 → 8.1 t 이고 작은 쪽 8.1 t 가 답이다. 예제 값과 같다.

## 7. 입력값 정하기

### 7.1 마찰계수 µ (부록 B, normative)

IRU 가이드에 실린 EN 12195-1:2010 부록 B 값이다. 표면이 깨끗하고 손상 · 성에 · 얼음이 없을 때만 유효하고,
그렇지 않으면 **µ = 0.2** 를 써야 한다.

| 접촉면 | µ |
|---|---|
| 제재목 – 합판 · 적층판 | 0.45 |
| 제재목 – 홈 있는 알루미늄 | 0.40 |
| 제재목 – 수축 필름 | 0.30 |
| 제재목 – 스테인리스 판 | 0.30 |
| 대패목 – 합판 · 적층판 | 0.30 |
| 대패목 – 홈 있는 알루미늄 | 0.25 |
| 대패목 – 스테인리스 판 | 0.20 |
| 플라스틱 팔레트 – 합판 · 적층판 | 0.20 |
| 플라스틱 팔레트 – 알루미늄 · 스테인리스 | 0.15 |
| 강철 상자 – 합판 · 적층판 | 0.45 |
| 강철 상자 – 홈 있는 알루미늄 | 0.30 |
| 강철 상자 – 스테인리스 판 | 0.20 |
| 거친 콘크리트 – 제재목 받침 | 0.70 |
| 매끈한 콘크리트 – 제재목 받침 | 0.55 |
| 고무 (미끄럼 방지) | 0.60 |

**우리 화물 · 판 조합은 표에 없을 가능성이 크다. 직접 잰다.**
부록 B 는 경사 시험(B.1.2)으로 µ 를 구하는 방법을 둔다.
판을 천천히 기울여 화물이 미끄러지기 시작하는 각도 φ 를 IMU 로 읽으면 정적 마찰 `µs = tanφ` 다.
검색 요약에 따르면 표 값은 "정적 측정 × 0.925"와 "동적 측정"의 평균이다(원문 미확인).
그래서 정적만 재면 `0.925·tanφ` 도 약간 낙관적인 값이다.
여러 번 재서 가장 작은 φ 를 쓰고, 재기 전까지는 기본값 **µ = 0.2** 로 둔다.

### 7.2 LC — 우리 모형의 허용 힘

모형용 벨트에는 LC 라벨이 없다. **연결된 부품 중 가장 약한 것의 정격**을 LC 로 잡는다.

- 인장형 셀 SparkFun 10 kg → **98 N** (README 기준)
- 벨트 · 버클 · 고리 정격이 이보다 낮으면 그 값

LC = 98 N 이면 조임 상한 0.5 LC = **49 N** 이다.
참고로 현재 `sensors/sim.py` 의 가짜 조임 장력(55 N, 60 N)은 이 상한을 넘는다.

### 7.3 벨트 각도 α

`α = atan(화물 높이 / (화물 모서리 ~ 고리 수평거리))`.
예를 들어 폭 14 cm · 높이 15 cm 상자를 판 가운데 두고 판 동서 끝(44.8 cm)에 고리를 달면 α ≈ 44° 다.
고리를 화물 가까이 붙일수록 α 가 커지고 필요 장력이 준다.

### 7.4 가속도 c — 두 가지를 같이 쓴다

1. **설계값 (출발 전 점검)**: 표 2 의 0.8 / 0.5 / 0.5. 표준을 따른다는 근거가 된다.
2. **실측값 (주행 중)**: 대차 · 판에 고정된 IMU 의 `ax_peak`, `ay_peak`, `az`.
   판과 같이 움직이는 가속도계는 화물이 느끼는 힘(관성 + 중력)을 그대로 재므로, 경사로 · 문턱 기울기도 자동으로 들어간다.

## 9. 검증 시험 (부록 D)

부록 D(normative)는 계산 대신 **실제 시험**(주행 시험, 경사 시험)으로 고박을 검증하는 방법을 둔다.
대회 시연과 판정 검증에 쓰기 좋다.

- **전도**: 경사각 φ 에서 `tanφ = c` 면 측방 0.5 g 와 같다. 측방 0.5 g 는 26.6°, 전방 0.8 g 는 38.7° 다.
  IRU 가이드의 포장 안정성 시험이 바로 이 각도다.
- **미끄럼**: 경사에서는 바닥 수직력도 cosφ 로 줄어서 각도가 µ 에 따라 달라진다.
  아래 표는 우리가 `sinφ − µ·cosφ = c − µ` 로 **직접 유도한 값**이다(표준 문구 아님, fs 미포함).

| µ | 0.5 g 상당 | 0.8 g 상당 |
|---|---|---|
| 0.2 | 28.4° | 47.3° |
| 0.3 | 27.7° | 45.3° |
| 0.45 | 26.8° | 42.8° |

시연 방법: 판을 기울이면서 IMU 각도, 장력 셀, 무게중심을 같이 기록한다. 시스템이 예측한 미끄럼 각도와 실제로 미끄러진 각도를 비교한다.

## 10. 구현 계획 — 북 · 남 벨트 2개

> **2026-10-07 실제 구현 (`analysis/tension.py`)** — 아래 계획 중 벨트별 하한 · 상한 4단계만 들어갔다.
> 실시간 여유, 느슨해짐, 북남 불균형 같은 나머지는 아직 후보다.
>
> | 단계 | 장력 / 하한 | 장력 / 상한(`TENSION_MAX`, LC) |
> |---|---|---|
> | 정상 | 100% 이상 | 50% 이하 |
> | 주의 | 100% 밑 (EN 하한 미달) | 50% 넘음 (과조임) |
> | 경고 | 75% 밑 | 75% 넘음 |
> | 위험 | 50% 밑 (풀림) | 100% 넘음 (상한 넘음) |
>
> - 하한 = 맡은 무게 × g(A − µ)·fs / (2µ sinα), fs = 1.1. 최소 1 N/kg 이고 `TENSION_FLOOR` 밑으로도 내리지 않는다.
> - 벨트마다 맡는 무게는 계획의 `max(s, 0.5)` 몫 대신 지렛대 몫을 쓴다 (2026-10-15).
>   벨트 누름을 뺀 화물 무게중심 y_c 가 두 벨트 위치 y_N · y_S(`BELT_N_Y` · `BELT_S_Y`) 사이 어디인지로
>   N 몫 = (y_S − y_c) / (y_S − y_N), S 몫 = 1 − N 몫 (0~1 로 자름).
>   그 전에는 그쪽 두 셀 합(N = NW+NE, S = SW+SE)에서 그 벨트 누름을 뺐다. 벨트가 셀 줄 위에 있다고 본 셈이라,
>   S 벨트가 판 가운데 쪽이면 S 누름 일부가 앞쪽 셀에 실려 S 를 조일수록 N 하한이 올라갔다.
> - 벨트 고리는 판 아래(차체)에 걸려 있다. 그래서 10.1 의 "고리는 판 위" 권고 대신 셀 값에서 벨트 누름을 빼서 보정한다
>   (`total.py` 는 합으로, `cog.py` 는 벨트 위치에서 빼서 무게중심까지 보정. 장력 · 무게중심 · 화물 이동 판정이 이 무게중심을 같이 쓴다).

### 10.1 배치

`COG_CORNERS=NW,NE,SW,SE` 가 (앞왼, 앞오, 뒤왼, 뒤오) 이므로 **북 = 앞(진행 방향), 서 = 왼쪽**으로 본다.
판은 남북 59.2 cm, 동서 44.8 cm 다. 벨트 2개를 **동서 방향으로 화물 위에 넘기고**, 북쪽 벨트 TN 과 남쪽 벨트 TS 로 나눈다.

```
                 N (앞)
   NW +-----------------------------+ NE
      |  [c]=======TN=========[R]   |    TN: 래칫 동쪽, 셀 서쪽 다리
      |         +---------+         |
   W  |         |  cargo  |         |  E
      |         +---------+         |
      |  [R]=======TS=========[c]   |    TS: 래칫 서쪽, 셀 동쪽 다리
   SW +-----------------------------+ SE
                 S (뒤)
   [R] 래칫(조임쇠)   [c] 장력 셀
```

- **래칫은 번갈아 둔다** (5.3). TN 은 동쪽, TS 는 서쪽.
- **셀은 래칫 반대쪽 다리에 단다.** 모서리 마찰로 장력이 낮은 쪽이라 이 값을 2배 하면 보수적이다.
  fs 는 그대로 곱한다(이중 여유).
- **벨트 고리는 판(로드셀 위)에 단다.** 고리가 대차 프레임(로드셀 아래)에 있으면
  벨트가 화물을 누르는 힘 `2·T·sinα` 가 바닥 셀에 더해져서 무게와 무게중심이 틀어진다.
  판 위 고리면 이 힘은 판 안에서 상쇄된다.
- 지금 `acquisition/env.sh` 는 장력 셀이 `c1` 하나다. HX711 채널 하나를 더 배선해서 `HX_TENSION=TN,TS` 로 둔다.

### 10.2 판정 흐름

```
Frame (load_g, tension_n, imu)
  │
  ├─ 질량 m = 바닥 셀 합                      (Result.total_g)
  ├─ 벨트별 몫 sN = (NW+NE)/m, sS = 1 − sN     → s' = max(s, 0.5)
  │
  ├─ [A] 출발 전 점검 (정지 상태)     설계 가속도로 EN 식 10/16
  ├─ [B] 주행 중 점검                 IMU 실측 가속도로 실시간 여유
  └─ [C] 추세 점검                    느슨해짐, 북남 불균형, 화물 이동
        → Lashing 결과 (벨트별 상태 + 전체 수준 ok / warn / danger)
```

**벨트별 몫 s'**: 무게가 북쪽에 쏠리면 북쪽 벨트가 더 많이 맡는다고 본다.
`max(s, 0.5)` 로 바닥을 깔아서 대칭 배치일 때는 표준과 같고(각 벨트가 m/2), 쏠리면 더 엄격해진다.
바닥 셀 무게중심이 바깥쪽으로 6~10 cm 틀어지는 문제가 있지만, 몫을 키우는 쪽이라 판정은 보수적으로 틀린다.

벨트 i 의 필요 장력은 다음과 같다. 방향마다 계산해서 가장 큰 값을 쓴다.

```
need_i(방향) = s'_i · m·g·(c − µ·cz)·fs / (2·µ·sinα)
```

### 10.3 판정 규칙

| 판정 | 조건 | 수준 | 근거 |
|---|---|---|---|
| 장력 부족 | 정지 중 `T_i < need_i` (설계 가속도) | 위험 | EN 식 10 · 16 |
| 진동 최소 미달 | `T_i < 1 N/kg × s'_i·m` | 주의 | EN 4.1, IRU |
| 과조임 | 정지 중 `T_i > 0.5 LC` | 주의 | IRU (래칫 요건) |
| 과부하 | `T_i` 최대치 `> LC` | 위험 | LC 정의 |
| 불안정 화물 장력 상승 | 불안정 판정이고 `T_i` 최대치 `> 0.5 LC` | 위험 | EN 5.1 |
| 실시간 여유 부족 | `ΣT / need_live < 1.0` (`< 1.5` 는 주의) | 위험 | 식 10 + IMU |
| 느슨해짐 | `T_i < 0.8 × T_i,출발` 상태가 0.5 s 지속 | 주의 | IRU 재조임 권고 |
| 북남 불균형 | `abs(TN − TS) / max(TN, TS) > 0.3` | 주의 | EN 5.1 대칭 가정 |
| 화물 이동 | 정지 후 CoG 가 출발 때보다 20 mm 넘게 이동하고 장력이 떨어짐 | 위험 | 우리 규칙 |
| 벨트 각도 | `α < 30°` | 주의 | IRU |

- 0.8, 0.3, 20 mm, 0.5 s, 1.5 는 **표준 값이 아니라 우리가 정한 시작값**이다. 기록 데이터로 조정한다.
- **실시간 필요 장력**: `need_live = m·g·(|a_h| − µ·a_z)·fs / (2·µ·sinα)`.
  `a_h` 는 그 프레임의 `ax_peak` · `ay_peak` 이고, 방향에 맞는 fs 를 쓴다. 제동이면 전방이라 1.25 다.
- **정지 판정**: `|ax|, |ay| < 0.05 g` 이고 `|gz| < 2 °/s` 인 상태가 1 s 지속.
  정지 → 주행으로 바뀌는 순간 직전 2 s 장력 중앙값을 `T_i,출발` 로 잡는다.
- **불안정 판정**: 무게중심 높이는 바닥 셀로 알 수 없고 카메라는 판정에 쓰지 않는다.
  그래서 화물 치수(높이 · 폭 · 길이)를 설정으로 받고, 무게중심은 화물 한가운데로 가정한다.
- 10 Hz 장력 값에는 HX711 노이즈가 있으므로 조건이 몇 프레임 이어질 때만 판정한다.

### 10.7 정할 것

- 벨트 방향: 이 문서는 **동서로 넘기는 벨트 2개(북 · 남)** 로 가정했다.
  만약 남북으로 넘기는 벨트 1개의 양쪽 다리에 셀을 단다는 뜻이었다면, 두 값의 비가 곧 k 계수다.
  그 경우 `ΣT = T_N + T_S` 로 바로 쓰고, 벨트별 몫 대신 다리 간 손실률을 본다.
- 실제 진행 방향이 북쪽이 맞는지 (`COG_CORNERS` 순서 기준으로 가정함).
- 앞막이(블로킹) 유무 → 전방 판정을 켤지.
- 화물 치수를 어디서 입력할지 (환경변수 / display 화면).
- 모형 벨트 · 고리의 정격 → LC.
