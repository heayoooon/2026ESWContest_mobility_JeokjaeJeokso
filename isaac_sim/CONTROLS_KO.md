# 적재적소 디지털 트윈 – 조종 안내 (팀원용)

## 0. 처음 한 번만 준비
1. 내 PC에 **Tailscale**을 설치하고 팀 tailnet(**alaskaa-yjh**)에 로그인합니다. 같은 공유기(와이파이)에 있으면 생략 가능.
2. 브라우저는 **Chrome 또는 Edge**를 씁니다.
3. 호스트 PC(김단하 PC)에서 Isaac Sim이 **공유 모드**(`Start-ForestTwin-Share.bat`)로 켜져 있어야 합니다. 안 열리면 호스트에게 켜 달라고 하세요.

## 빠른 따라 하기 (처음이면 이 순서대로)
1. 스트림 주소 열기 → **▶** → 화면 한 번 클릭
2. 오른쪽 패널 **시점 → `앞`** 로 트럭이 잘 보이게
3. **`측정 재생`** 에서 기록 상자로 원하는 측정 기록 선택 → 트럭이 실측 IMU대로 달리고, **판정 · 센서** 에 실측 판정이 나옵니다
4. 기록이 필요하면 **`기록 시작`** → 원하는 만큼 본 뒤 **`기록 정지`**
5. 직접 실험하려면 **`물리 실험`** → `출발` / `좌회전` / `우회전` / `정지`, **화물 · 벨트 · 물리** 에서 무게·마찰·벨트 바꾸기, `벨트 모두 풀기` 로 화물 밀림 보기
6. 다 보면 다운로드 페이지에서 기록 ZIP 받기 → **스트림 탭 닫기**(다음 사람 차례)

## 1. 접속 (원격 보기 + 조종)
1. Chrome 또는 Edge에서 아래 주소 중 하나를 엽니다 (한 번에 **1명**만 접속 가능).
   - 같은 공유기: `http://192.168.0.17:8211/streaming/webrtc-demo/?server=192.168.0.17`
   - Tailscale: `http://100.109.1.106:8211/streaming/webrtc-demo/?server=100.109.1.106`
2. 가운데 빨간 **▶** 를 누르면 화면이 나옵니다.
3. 화면을 **한 번 클릭**해 포커스를 준 뒤 마우스·키보드를 쓰세요 (포커스가 없으면 입력이 브라우저로 갑니다).
4. 다 보면 탭을 닫거나 아래 **Stop** 을 눌러 다음 사람에게 자리를 넘깁니다.

> 오른쪽 패널은 한국어로 표시됩니다 (원격 조종 API 의 이름은 영어 그대로: 예 `pretension_c1`, `straps_c2`).
> 키보드 단축키는 따로 없습니다. 조종은 **오른쪽 패널의 버튼·슬라이더**와 **뷰포트 마우스 조작**으로 합니다.

## 2. 마우스 (3D 화면)
| 동작 | 조작 |
|---|---|
| 회전(돌려보기) | **Alt + 왼쪽 버튼 드래그** |
| 이동(옆으로 밀기) | **Alt + 가운데 버튼 드래그** |
| 확대/축소 | **마우스 휠** 또는 Alt + 오른쪽 버튼 드래그 |
| 날아다니기 | **오른쪽 버튼 누른 채 W/A/S/D** (Q 아래, E 위) |
| 물체 선택 해제 | **Esc** |

- `트럭 따라가기`이 켜져 있으면 Alt-회전으로 잡은 각도를 트럭이 달리면서도 그대로 유지합니다. 카메라가 트럭 안으로 들어가면 자동으로 기본 뷰로 돌아옵니다.
- **물리 실험 모드에서는 화물을 마우스로 옮길 수 있습니다**: 화물을 클릭 → **W**(이동) 또는 **E**(회전) → 화살표를 끌어 옮기고 **마우스를 놓는 순간** 실제 물리 화물이 그 자리로 옮겨져 로드셀 · 벨트 장력 · 판정이 바뀝니다. 다른 물체(트럭 · 판 · 나무)는 옮기지 마세요. 실수했으면 **Esc** 후 `처음부터`.
- **측정 재생 모드에서 화물을 옮기면** 자동으로 `물리 실험` 로 바뀌고, 화물이 판 위의 같은 자리에 놓여 COG · 로드셀 · 벨트 · 판정이 그 위치로 계산됩니다 (측정 재생은 실제 녹화 센서값을 그대로 틀기 때문에 그 상태로는 바뀔 수 없습니다). 다시 녹화 재생을 보려면 `측정 재생`.
- 일시정지(`일시정지`) 중에 옮겨도 바로 COG · 로드셀 · 벨트 · 판정이 바뀝니다 (일시정지 = 세워 둔 트럭).
- 출발 · 제동할 때 COG 앞뒤(Y)가 20 mm 정도 바뀌는 것은 화물이 움직인 게 아니라 무게가 뒤 / 앞으로 쏠리는 하중 이동입니다 (CSV `cargo_offset_mm` 이 그대로면 화물은 제자리).
- **Delete** 키는 핵심 물체(적재함·트럭·플레이트)에 막혀 있습니다.

## 3. 오른쪽 패널
### 맨 위 (모드·기록)
| 버튼/슬라이더 | 기능 |
|---|---|
| `측정 재생` | 라즈베리파이로 **실제 측정한 기록**을 재생 (로드셀·벨트·IMU·깊이카메라) |
| `물리 실험` | PhysX **물리 실험 모드** (화물이 실제로 밀리고 떨어짐) |
| 기록 선택 상자 | 14개 기록 중 선택 (`월/일 시:분 제목`) |
| `재생 / 일시정지` | 재생 / 일시정지 |
| `처음부터` | 화물 제자리, 처음부터 |
| `내보내기` | USD·JSON·CSV·깊이 배열·스크린샷을 `exports/날짜_시각/`에 저장 |
| `고화질 사진` | 경로추적 고화질 사진 1장 (10~20초 화면 정지 후 `exports/…_hq/photo.png`) |
| `기록 시작` (초록) | **데이터 기록 시작** — 누르기 전에는 아무것도 저장하지 않음 |
| `기록 정지` (빨강) | **기록 정지** — 파일을 닫고 요약 저장 |
| `재생 위치 (초)` | 재생 위치 이동 |
| `재생 속도 (배)` | 재생 속도 0.1~3배 |
| `끝나면 반복 재생` | 끝나면 반복 |

### 도로 · 주행
| 항목 | 기능 |
|---|---|
| `출발` | 순항 속도로 출발 (기본 20 km/h). 일시정지 중이면 일시정지도 풀고 출발 |
| `정지` | 정지 (속도 0) |
| `좌회전` / `우회전` | 좌/우 회전 (±25 °/s) |
| `직진` | 직진 |
| `순항 속도 (km/h, - 후진)` | −10 ~ 60 (음수 = 후진) |
| `가속 · 제동 (m/s²)` | 가속도 |
| `회전 (도/초, + 왼쪽)` | + 왼쪽 / − 오른쪽 |
| `차선 위치 (m, + 왼쪽)` | 차선 위치 (+ 왼쪽, 기본 −5.25 = 바깥 오른쪽 차선) |
| `도로 경사 (도, + 오르막)` | 오르막/내리막 −25~25 |
| `도로 좌우 기울기 (도)` | 좌우 기울기 −15~15 |
| `재생: 기록된 IMU대로 달리기` | **켜짐**: 측정 재생 때 기록된 IMU대로 달림 / **끄면** 위 버튼·슬라이더로 직접 운전 |
| `재생: 회전 반영 비율` | 기록된 회전을 얼마나 반영할지 0~1 |
| `차체 기울기 (도/G)` | 가속·제동 시 차체 기울기 |

> **직접 운전하려면**: `물리 실험` 모드이거나, `측정 재생`에서 `재생: 기록된 IMU대로 달리기`를 끄세요.

### 화물 · 벨트 · 물리 (제목을 클릭하면 펼쳐짐)
| 항목 | 기능 |
|---|---|
| `화물 무게 (kg)` | 화물 무게 0.1~30 (기본 14) |
| `차량 무게 (kg)` | 차량 무게 |
| `바닥 마찰 계수` | 바닥 마찰 0.05~1.5 (기본 0.6). 화물은 **마찰 × (화물 무게 + 벨트 누름)** 이 가감속 · 커브 · 경사로 미는 힘보다 크면 판에 고정되고, 작아지면 미끄러집니다 (CSV `cargo_secured`, `grip_demand_N`, `grip_capacity_N`) |
| `화물 앞뒤 (m, + 뒤쪽)` / `화물 좌우 (m, + 오른쪽)` | 화물 위치 치우침 |
| `두 벨트 조임 (N)` | 두 벨트 조임을 한 번에 0~98 N (기본 8) |
| `앞벨트 c1 조임 (N)` / `뒷벨트 c2 조임 (N)` | **앞벨트(c1) · 뒷벨트(c2) 조임을 따로** 0~98 N. 장력 셀도 벨트마다 따로 읽습니다 |
| `벨트 강성 (N/m)` | 벨트가 늘어날 때 장력이 얼마나 빨리 오르나 (기본 1500, 100~5000) |
| `두 벨트 연결` | 두 벨트를 한 번에 연결/해제. 벨트는 **로프처럼** 화물 위를 감아 넘어가고, 늘어나면 당기고 느슨하면 0 (밀지 않음) |
| `앞벨트 c1 연결` / `뒷벨트 c2 연결` | **앞벨트 · 뒷벨트를 따로** 연결/해제 (예: 뒷벨트만 풀기). 푼 벨트의 장력 셀은 0 N |
| `스캔한 화물 모양 (물리 실험)` | 스캔한 실제 화물 모양 사용 |
| `벨트 모두 풀기` | 벨트를 풀어 화물이 밀리는지 보기 |
| `화물 제자리에 다시 놓기` | 화물 다시 제자리 |

## 4. 데이터 기록 (Start / Stop recording)
1. `재생 / 일시정지` 줄 바로 아래 **초록 `기록 시작`** 버튼을 누릅니다.
2. 버튼이 **빨간 `기록 정지`** 으로 바뀌고 옆에 `● 기록 중 00:12  120줄`처럼 기록 시간과 줄 수가 올라갑니다.
3. 원하는 만큼 재생·운전·실험을 합니다. 모드를 바꾸거나 기록(run)을 바꿔도 계속 기록됩니다.
4. **`기록 정지`** 을 누르면 저장이 끝나고 `저장됨 120줄 (12초)`가 표시됩니다.

저장 위치: `IsaacTwin\recordings\날짜_시각\`

| 파일 | 내용 |
|---|---|
| `twin_log.csv` | 0.1초마다 한 줄 (엑셀로 바로 열림) |
| `twin_log.jsonl` | 같은 내용 (프로그램 분석용) |
| `summary.json` | 시작 시각, 길이, 줄 수, 사용한 run, 최고 위험 등급 |

CSV 열: 기록 시간 · 시계 · 모드(measured/physics) · run · 재생 시간 · 차량 속도(km/h) · 루프 위치 · 차선 · 방향 · 경사 · 좌우기울기 · 화물 무게 · 벨트 연결 → 그 뒤로 로드셀 4개(g), 벨트 장력 c1/c2(N), IMU 2개, 무게중심, 판정 등급(risk, lv_load, lv_cog, lv_c1, lv_c2 …).

- Isaac Sim을 켜기만 해서는 **아무것도 저장되지 않습니다.**
- 기록 중에 Isaac Sim 창을 닫아도 그때까지의 기록은 안전하게 저장됩니다.
- 원격 접속자가 눌러도 파일은 **이 PC**에 저장됩니다.

### 팀원이 기록 파일 받기
브라우저에서 아래 주소를 엽니다 (스트림 화면과 **따로**, 여러 명이 동시에 열어도 됨):
- Tailscale: `http://100.109.1.106:8211/recordings/`
- 같은 공유기: `http://192.168.0.17:8211/recordings/`

기록마다 **ZIP 전체 받기**(CSV+JSONL+요약)와 파일별 링크가 있습니다. 기록 중인 것은 `기록 중…`으로 표시되고, Stop을 누른 뒤 새로고침하면 받을 수 있습니다. Isaac Sim이 **공유 모드**(`Start-ForestTwin-Share.bat`)로 켜져 있을 때만 열립니다.

## 5. 내 Claude로 조종하기
화면을 보지 않아도 **각자의 Claude**가 트윈을 조종할 수 있습니다 (스트림 보는 사람과 동시에 가능, 같은 트윈을 움직임).
안내 페이지: `http://100.109.1.106:8211/twin/` (같은 공유기: `http://192.168.0.17:8211/twin/`)

**Claude Code** (추천)
1. 안내 페이지에서 `isaac_twin_mcp.py` 를 내려받습니다 (Python 3만 있으면 됨).
2. 터미널에서 한 번만 등록합니다:
   ```
   claude mcp add isaac-twin -- python 내려받은경로/isaac_twin_mcp.py --url http://100.109.1.106:8211
   ```
3. Claude에게 그냥 말합니다:
   - "트윈 상태 보여줘"
   - "뒷벨트없음화물이동 기록 틀고 화면 캡처해줘"
   - "물리 모드로 바꾸고 경사 10도, 벨트 풀어서 화물 이동 판정 확인해줘"
   - "뒷벨트만 풀고 앞벨트는 30 N 으로 조여서 장력 판정 보여줘"
   - "기록 시작하고 20초 달린 뒤 멈추고 디스플레이로 보내줘"

**Claude Desktop**: 설정 → 개발자 → 구성 편집(`claude_desktop_config.json`)에 넣고 다시 시작
```
"mcpServers": {"isaac-twin": {"command": "python", "args": ["내려받은경로/isaac_twin_mcp.py", "--url", "http://100.109.1.106:8211"]}}
```

Claude가 쓰는 도구: 상태 읽기 · 명령 목록 · 조종(모드, 기록 선택, 재생, Go/Brake/좌우, 모든 슬라이더, 시점, 기록 시작/정지,
디스플레이로 보내기, 고화질 사진) · **화면 캡처(이미지)** · 기록 목록 · 기록 ZIP 내려받기.
MCP 없이도 Claude Code에 "`http://100.109.1.106:8211/twin/commands` 를 읽고 이 트윈을 조종해" 라고 하면 curl로 조종합니다.
Claude가 바꾼 내용은 패널 맨 아래 상태 줄에 `원격 조종: …` 로 표시됩니다.

## 6. 디스플레이 파이로 보내기
**`디스플레이로 보내기`** 를 한 번 누르면 **지금 트윈 상태를 디스플레이 파이 트윈 화면으로 계속(초당 10프레임) 보냅니다.**
`디스플레이 멈춤` 를 누를 때까지 멈추지 않고, 디스플레이 앱을 껐다 켜도 자동으로 다시 연결합니다.
- 측정 재생 · 물리 실험 어느 쪽이든 그대로 나옵니다. 물리 실험에서 **벨트 조임(Strap preload) · 강성 · 경사 · 화물 무게**를
  바꾸면 디스플레이의 장력 · 판정이 바로 바뀌고, 화물이 밀리면 디스플레이의 3D 상자도 같이 움직입니다 (판 밖으로 떨어지면 사라짐).
- 버튼 옆에 `디스플레이: 실시간 보내는 중 - 1234 프레임 보냄` 처럼 보낸 프레임 수가 올라갑니다.
- 저장한 기록을 보내려면 다운로드 페이지(`/recordings/`)의 **디스플레이로 보내기** 버튼 → 그 기록을 **반복 재생**합니다 (멈출 때까지).
- Claude: "디스플레이로 실시간 보내줘" / "기록 20261020_211833 디스플레이로 보내줘" / "디스플레이 보내기 멈춰".
- 디스플레이 파이가 켜져 있고 트윈 앱(바탕화면 아이콘)이 실행 중이어야 합니다. 꺼져 있으면 `디스플레이: 연결 기다리는 중 …` 로 기다립니다.
- **센서 파이가 실시간으로 보내는 중이면** 디스플레이는 그 연결을 먼저 읽습니다. 센서 파이에서 `~/scss_live/stop_live.sh` 후 보내세요.
- 카메라 높이맵은 그 기록의 원래 D435i 프레임입니다 (물리 실험은 첫 프레임의 화물을 트윈이 계산한 만큼 옮겨서 보냄).

## 6-1. 실시간 받기 (센서 파이 → 아이삭 트윈)
**`실시간 받기`** 를 누르면 기록 대신 **센서 파이가 지금 보내는 값**으로 트윈이 움직입니다: 적재함 위 화물 모양(D435i 깊이),
로드셀 4개 · 벨트 2개 · IMU, 그리고 팀 판정 코드로 다시 낸 판정. 다시 누르면(`실시간 멈춤`) 고른 기록 재생으로 돌아갑니다.
- 센서 파이는 디스플레이 파이로 보내는 것과 **같은 프레임을 이 PC(포트 5010)로도** 보내야 합니다:
  센서 파이에서 `~/scss_live/run_live.sh 100.90.251.42 100.109.1.106:5010` (첫 번째 = 디스플레이 파이, 두 번째 = 이 PC).
  이 PC로 보내는 일은 따로 돌아서, 트윈이 꺼져 있어도 디스플레이 화면은 느려지지 않습니다.
- 버튼 옆에 `실시간: 센서 파이에서 받는 중 (… 9.8 Hz, 지연 0.05초)` 처럼 받는 속도와 지연이 나옵니다.
- 화물 모양은 초당 약 10번 바뀝니다 (카메라는 초당 30장이지만 센서 파이가 10장만 처리해서 보냄). 테일스케일을 거쳐 0.1~0.3초 늦을 수 있습니다.
- 트럭은 실제로 달리지 않으므로 트럭 움직임은 `도로 · 주행` 슬라이더대로입니다.
- **`화물을 상자로 (디스플레이 파이 방식)`** (기본 켜짐): 화물을 디스플레이 파이와 **같은 코드**(팀 `display/twin/server` 의
  `cargo_model` · `stable_twin` · `stack_layers`)로 반듯한 상자로 만들어 보여 줍니다. 1초 동안 기준을 잡고, 0.5초 넘게 이어진 변화만
  반영하므로 깊이 카메라 잡음으로 출렁이지 않습니다. 끄면 카메라 깊이 그대로의 표면이 나옵니다. 측정 재생에도 똑같이 적용됩니다.
- Claude: "실시간 받아" / "실시간 멈춰" (API `live`).

## 7. 판정 알고리즘 = 우리 센서 파이 코드
트윈의 모든 판정(적재 · 무게중심 · 화물 이동 · 앞/뒤 벨트 · 종합)은 **팀 저장소의 센서 파이 코드(`pi/analysis`)를 그대로** 돌린 결과입니다.
패널 **판정 · 센서** 첫 줄에 `판정: team dev@d4fe723` 처럼 쓰인 코드 버전이 나옵니다.
- **측정 재생**: 기록된 원시값(셀 4개 · 벨트 2개 · IMU)을 0.1초마다 팀 `Analyzer` 에 다시 넣어 판정 → 기록 당시와 판정 기준이 바뀌었으면 새 기준으로 나옵니다.
- **물리 실험**: 시뮬레이션 센서값을 0.1초마다 같은 `Analyzer` 에 넣어 판정 → 알고리즘을 트럭 위에서 실험해 볼 수 있습니다.
  시뮬레이션 센서는 실물처럼 만들었습니다: 벨트가 누르는 힘이 셀에 더해지고, 가감속 · 커브 · 경사에서 하중이 이동하며(h 190 mm), 셀은 IMU보다 0.2초 늦게 반응합니다.

## 8. 자주 겪는 문제
- **화면이 안 나와요** → 다른 사람이 접속 중입니다. 그 사람이 탭을 닫아야 합니다.
- **클릭해도 반응이 없어요** → 영상 화면을 한 번 클릭해 포커스를 주세요.
- **Go를 눌러도 안 가요** → `측정 재생` + `재생: 기록된 IMU대로 달리기` 켜짐 상태입니다. 토글을 끄거나 `물리 실험`로 바꾸세요.
- **카메라가 이상한 곳에 있어요** → `앞` 버튼.
- **주소가 아예 안 열려요** → Tailscale이 켜져 있는지, 호스트 PC에서 공유 모드 Isaac Sim이 켜져 있는지 확인하세요.
- **화면이 끊기거나 지지직거려요** → 오른쪽 **시점** 칸의 `화질` 을 **보통** 또는 **고화질** 로 바꿔 보세요. 그래도 끊기면 네트워크 영향이니 탭을 닫고 다시 접속하세요.
- **물건이 사라졌거나 옮겨졌어요** → `Esc` → `처음부터`.
